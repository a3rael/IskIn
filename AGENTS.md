# ИскИн

Этот репозиторий разрабатывает универсальную систему agent-native PDLC «ИскИн» для Hermes Agent и Hermes Desktop.

## Карта источников

- `package/` — устанавливаемая часть ИскИн; только она переносится в пользовательский продукт.
- `installer/` — установка и проверка пакета.
- `docs/` — цель, архитектура, решения, руководство и дорожная карта.
- `experiments/` — исторические наблюдения; читай их при анализе гипотез и потерь, но не применяй как активные правила.

Budget в `experiments/budget-ios/` — завершённый первый полигон. Его P0, G1—G5, Swift/XCTest/XCUITest, evidence scopes и заполненная продуктовая память не являются правилами ИскИн.

## Работа над ИскИн

Перед изменением пакета восстанови цель из `docs/vision/purpose.md` и отдели универсальное ядро, Hermes-интеграцию и настройки продукта. Используй Budget только как источник доказанных наблюдений. Любой перенос из эксперимента в `package/` сначала обобщи и проверь на отсутствие продуктовых деталей.

Человек утверждает цель ИскИн, политику автономности, установочный контракт, состав стабильного выпуска и внешнюю публикацию. GitHub Release, push, remote и разработка v0.4 начинаются только после отдельного решения человека.

## Локальные коммиты разработки

Для разработки самого репозитория ИскИн Hermes создаёт локальный коммит только после обязательных проверок по составу изменения. Каноническая политика: `docs/decisions/2026-09-02-local-commit-policy.md` и `docs/development/verification-policy.md`. Она не распространяется на устанавливаемый `package/template/**`; remote, push, тег и release всегда требуют отдельного разрешения человека.
