# Дорожная карта

## v0.3

`0.3.0` — стабильная принятая исходная версия ИскИн и baseline для дальнейшего развития и экспериментов v0.4. В неё входят утверждённые границы из `docs/decisions/2026-09-02-v0.3-boundaries.md`.

Решение о принятии зафиксировано в `docs/decisions/2026-09-06-v0.3-baseline-acceptance.md`. Локальные коммиты разработки самого репозитория выполняются только по `docs/decisions/2026-09-02-local-commit-policy.md` и `docs/development/verification-policy.md`. Создание или изменение remote, `push`, tag и публикация остаются отдельными решениями человека.

## Актуальные наблюдения о runtime-навыках (2026-09-05)

- Ранее текущие Desktop-сессии не загружали шесть проектных навыков ИскИн.
- Отдельный runtime-процесс с абсолютным `TERMINAL_CWD` загружал все шесть навыков.
- Финальная Desktop-сессия успешно загрузила все шесть навыков из текущего проекта при `TERMINAL_CWD=./workspace`.

Относительное значение `TERMINAL_CWD` само по себе не доказывает причину прежних отказов. Причина различия между сессиями пока не установлена. Успешная финальная runtime-проверка зафиксирована, но U-003 остаётся открытым до установления причины и подтверждения устойчивого контракта.

U-003 является известным неблокирующим ограничением Hermes Desktop и не отменяет принятие v0.3 как стабильного baseline. Это принятие не означает доказанную стабильность runtime Hermes во всех будущих сессиях.

## После v0.3

Все дальнейшие изменения ядра ИскИн относятся к v0.4 и начинаются только после отдельного решения человека.

### v0.4 — кандидаты после отдельного решения

- расследование причины различий runtime-сессий и при необходимости исправление U-003;
- повторная проверка runtime-каталога и загрузки навыков в Hermes Desktop;
- оценка гипотезы о переходе к глобальным навыкам Hermes, если она не ослабляет проектную изоляцию;
- усиление автоматического enforcement и второй полигон.

Эти пункты не входят в v0.3. Файловый fallback вместо runtime-навыков в v0.3 не добавляется. Улучшения v0.4 могут появиться только после отдельного решения человека и анализа телеметрии.
