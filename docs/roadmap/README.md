# Дорожная карта

## v0.3

Текущий выпуск — подготовка и статическая проверка универсального шаблона ИскИн и установочного контракта. В него входят утверждённые границы из `docs/decisions/2026-09-02-v0.3-boundaries.md`.

Переход к стабильной фиксации, тегу и внешней публикации требует отдельного решения человека. До него не выполняются commit, remote, release или push.

## После v0.3

Улучшения v0.4, второй полигон и усиление автоматического enforcement не проектируются и не реализуются в рамках v0.3. Они могут появиться только после отдельного решения человека и анализа телеметрии.
