## Восстановление

1. Проверить целостность:

   ```text
   cd /Users/rukavisnikovila/workspace/archives/iskin/v0.4/2026-09-13-full-cycle-6
   shasum -a 256 -c SHA256SUMS
   ```

2. Распаковать полный эксперимент в новый путь:

   ```text
   mkdir -p /path/to/restore
   tar -xzf iskin-v0.4-full-cycle-6-verified.tar.gz -C /path/to/restore
   ```

3. Проверить восстановленный Git-проект:

   ```text
   git -C /path/to/restore/iskin-v0.4-full-cycle-6 rev-parse HEAD
   git -C /path/to/restore/iskin-v0.4-full-cycle-6 status --porcelain
   git -C /path/to/restore/iskin-v0.4-full-cycle-6 fsck --full
   ```

   Ожидается `HEAD=fe06c2868e1ffbdf06713ccb923c267a4e7ce03e`, пустой `status` и успешный `fsck`.

4. Для восстановления release candidate распаковать второй архив в новый отдельный путь:

   ```text
   mkdir -p /path/to/restore/iskin-v0.4.0-rc
   tar -xzf iskin-v0.4.0-rc-checks-release-a-verified.tar.gz -C /path/to/restore/iskin-v0.4.0-rc
   ```

   Он восстановит только `checks/` и `release-a/`.

До отдельного решения восстановленные материалы не запускать: код, тесты, бота и внешние интеграции не выполнять.
