# Воспроизводимая локальная сборка release-комплекта ИскИн v0.3

**Дата:** 2026-09-02
**Статус:** утверждено человеком
**Тип:** технический контракт локального release generator
**Область:** development-only сборка release-комплекта; не входит в устанавливаемый шаблон

## Решение

Канонический интерфейс генератора:

```text
python3 installer/build_release.py \
  --release-version 0.3.0 \
  --output-dir /path/to/output
```

Генератор создаёт ровно три файла:

```text
iskin-v0.3.0.zip
install-iskin.py
SHA256SUMS
```

Источники ограничены:

- `package/template/` — единственный источник устанавливаемого шаблона;
- `installer/install-iskin.py` — единственный источник standalone-установщика;
- явно переданный `--release-version`;
- canonical-фабрика `package-manifest.json` v1 из standalone-источника установщика.

## Безопасность выходного каталога

`output-dir` может быть несуществующим или существующим пустым каталогом. Непустой каталог, каталог-симлинк, существующий release-файл или любая другая запись приводят к отказу без перезаписи.

Комплект сначала формируется в sibling staging-каталоге на той же файловой системе. До публикации выполняются:

1. проверка release read-only validator-ом;
2. пробная установка только во временный проект;
3. сравнение установленных байтов с `package/template/`;
4. проверка `.iskin/version` и `installation-manifest.json`;
5. повторный read-back готового комплекта.

Только после этого комплект публикуется в `output-dir`. Для новой папки используется атомарное переименование готового staging-каталога; для существующей пустой папки три файла переносятся эксклюзивно, без перезаписи. При обычной ошибке staging и созданные output-файлы удаляются.

## Детерминированность

ZIP создаётся одним фиксированным способом:

- записи отсортированы лексикографически;
- directory entries отсутствуют;
- используется `ZIP_STORED`;
- timestamps записей равны `1980-01-01 00:00:00`;
- Unix file attributes и permissions фиксированы как обычный файл `0644`;
- extra fields и ZIP comment пусты;
- архив содержит только `VERSION`, `package-manifest.json` и `template/**`.

Manifest записывается как UTF-8 JSON с LF, двумя пробелами, фиксированным порядком полей и одним завершающим переводом строки. `files` отсортирован по `path`; SHA-256 считается из фактических байтов.

`SHA256SUMS` содержит две отсортированные по имени строки, использует формат с двумя пробелами, LF и один завершающий перевод строки:

```text
<sha256>  install-iskin.py
<sha256>  iskin-v0.3.0.zip
```

В комплект не включаются время сборки, имя компьютера, абсолютные пути или другие нестабильные данные.

## Граница release

Локально созданный комплект является проверенным development-артефактом, но не означает стабильный release, human acceptance или production readiness. Generator не выполняет сеть, не создаёт remote, не выполняет push, не создаёт tag и не публикует GitHub Release. Tag, GitHub Release и push остаются отдельными human decisions.

Постоянные release-файлы не создаются в репозитории; генератор и его тесты используют только временные каталоги для результатов сборки и probe-установки.
