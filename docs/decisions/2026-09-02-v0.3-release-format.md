# Формат GitHub Release ИскИн v0.3

**Дата:** 2026-09-02
**Статус:** утверждено человеком
**Тип:** отдельное human decision о формате release-артефакта

## Решение

Официальный release ИскИн v0.3 содержит рядом в одном каталоге:

```text
iskin-v0.3.0.zip
install-iskin.py
SHA256SUMS
```

`SHA256SUMS` содержит SHA-256 архива `iskin-v0.3.0.zip` и установщика `install-iskin.py`.

## Структура архива

```text
iskin-v0.3.0/
├── VERSION
├── package-manifest.json
└── template/
    └── устанавливаемые файлы ИскИн
```

`VERSION` и поле `release_version` в `package-manifest.json` должны содержать `0.3.0`.

Точная схема `package-manifest.json` v1 зафиксирована отдельным решением `docs/decisions/2026-09-02-v0.3-package-manifest-v1.md`.

Архив не содержит `install-iskin.py` или `SHA256SUMS`.

Manifest schema v1 содержит ровно `schema_version`, `release_version`, `root`, `template_root` и `files`. В `files` находятся только записи `path` и `sha256`; список отсортирован и является полным allowlist файлов шаблона.

## Ограничения прототипа

Read-only проверяющий прототип проверяет этот формат, но не устанавливает пакет. Он не создаёт целевую папку, не распаковывает архив, не выполняет `git init`, не делает rollback, не подключает Hermes Desktop, не использует сеть и не устанавливает зависимости.

Реализация production-установщика, публикация GitHub Release и внешний release остаются отдельными действиями и не входят в это решение.
