# Уточнение наблюдений о runtime-навыках ИскИн v0.3

**Дата:** 2026-09-05
**Статус:** актуальное уточнение наблюдений; не изменяет human decision от 2026-09-03
**Тип:** наблюдение и граница вывода о совместимости с Hermes Desktop
**Область:** runtime-загрузка локальных проектных навыков ИскИн; не является продуктовой неопределённостью установленного проекта

## Новые наблюдения

Зафиксирована следующая последовательность наблюдений:

1. Ранее текущие Hermes Desktop-сессии не загружали шесть проектных навыков ИскИн.
2. Отдельный runtime-процесс с абсолютным `TERMINAL_CWD` загружал все шесть навыков.
3. Финальная Hermes Desktop-сессия успешно загрузила все шесть навыков из текущего проекта при `TERMINAL_CWD=./workspace`.

Во всех случаях runtime-доступность означает фактическую успешную загрузку каждого навыка по имени в соответствующей сессии, а не только наличие файла или запись в `hermes skills list`.

## Граница вывода

Эти наблюдения подтверждают, что результат runtime-проверки может различаться между сессиями и процессами. Относительное значение `TERMINAL_CWD=./workspace` само по себе не доказывает причину прежних отказов: финальная Desktop-сессия успешно загрузила навыки при том же значении.

Причина различия между прежними сессиями, отдельным процессом и финальной Desktop-сессией пока не установлена. Успешный контрольный процесс с абсолютным `TERMINAL_CWD` также не доказывает причинный механизм и не заменяет проверку конкретной Desktop-сессии.

## Статус U-003

Успешная финальная runtime-проверка зафиксирована как актуальное доказательство для этой сессии. U-003 не объявляется устранённым: остаются неопределёнными причина прежних расхождений и устойчивость runtime-контракта между сессиями.

Это уточнение не добавляет файловый fallback, не переносит навыки в глобальный каталог и не запускает работу над v0.4. Историческое решение от 2026-09-03 сохраняется без переписывания.
