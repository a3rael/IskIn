# Схема `package-manifest.json` v1 ИскИн

**Дата:** 2026-09-02
**Статус:** утверждено человеком
**Тип:** отдельное human decision о формате manifest
**Область:** release-пакет ИскИн v0.3; не является частью устанавливаемого шаблона

## Решение

В release-пакете используется только schema v1. Manifest имеет ровно следующие обязательные поля верхнего уровня:

```text
schema_version
release_version
root
template_root
files
```

Смысл полей:

- `schema_version` — целое число `1`;
- `release_version` — версия release ИскИн, например `0.3.0`;
- `root` — единственная корневая папка внутри ZIP, например `iskin-v0.3.0`;
- `template_root` — папка устанавливаемого шаблона внутри `root`; для v0.3 это `template`;
- `files` — полный список обычных файлов устанавливаемого шаблона и их SHA-256.

Каждая запись `files` имеет ровно два поля:

```text
path
sha256
```

## Правила schema v1

1. Пути в `files` считаются относительно `template_root`.
2. В `files` перечисляются только обычные файлы шаблона. `VERSION`, `package-manifest.json` и каталоги в список не входят.
3. Каждый файл шаблона указывается ровно один раз.
4. `files` отсортирован лексикографически по `path`.
5. `files` является точным allowlist: отсутствующие и лишние файлы запрещены.
6. Пути используют `/`, не являются абсолютными и не содержат `.`, `..`, обратных слешей, пустых компонентов или других опасных форм.
7. `sha256` содержит ровно 64 строчных шестнадцатеричных знака.
8. Неизвестные дополнительные поля верхнего уровня и внутри записей `files` запрещены.
9. `release_version` совпадает с версией, переданной валидатору, именем архива, содержимым `VERSION` и версией в `root`.
10. `root` имеет вид `iskin-v<release_version>`.
11. Manifest не содержит дату создания, абсолютные пути компьютера или другие недетерминированные данные.

## Граница enforcement

Read-only валидатор release обязан проверять все перечисленные правила до установки. Это решение фиксирует только schema-контракт; архитектура локального установщика и воспроизводимого generator зафиксирована отдельными техническими контрактами.

Схема относится к release-контракту репозитория ИскИн и не добавляется в `package/template/**`.
