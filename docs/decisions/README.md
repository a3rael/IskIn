# Решения ИскИн

Здесь хранятся отдельные решения о цели, архитектуре, установочном контракте и версиях ИскИн. Решения Budget сохраняются внутри его экспериментального снимка.

## Зафиксированные решения

- `2026-09-02-v0.3-boundaries.md` — утверждённые человеком границы, состав и исключения ИскИн v0.3.
- `2026-09-02-v0.3-release-format.md` — утверждённые человеком имена release-файлов и структура архива v0.3.
- `2026-09-02-v0.3-package-manifest-v1.md` — утверждённая человеком точная схема `package-manifest.json` v1.
- `2026-09-02-v0.3-safe-installation.md` — утверждённая человеком граница надёжности локальной установки ИскИн v0.3.
- `2026-09-02-v0.3-reproducible-release-build.md` — утверждённый человеком технический контракт воспроизводимой локальной сборки release-комплекта v0.3.
- `2026-09-03-v0.3-project-skill-runtime-boundary.md` — утверждённая человеком граница runtime-доступности локальных проектных навыков v0.3.
- `2026-09-02-local-commit-policy.md` — утверждённая человеком development-only политика локальных коммитов репозитория ИскИн.

Исторические решения Budget не являются решениями этого репозитория.
