# Решение v0.4: граница runtime-навыков ИскИн

**Дата:** 2026-09-06
**Статус:** утверждено человеком
**Тип:** отдельное human decision о составе и границе global skill bundle v0.4
**Область:** bundle `runtime/skills/` в репозитории разработки ИскИн; не установка в Hermes и не изменение v0.3

## Решение

Навыки v0.4 являются частью runtime ИскИн. Они проектируются специально для ядра ИскИн и могут предполагать структуру проекта и process contract ИскИн.

`runtime/skills/` — единственный канонический источник global skills ИскИн v0.4. Имена навыков используют namespace `iskin-`. Текущий bundle создаётся и проверяется в репозитории, но не устанавливается в Hermes этим решением.

## Граница применимости

Вне проекта со структурой ИскИн global skill возвращает `not applicable` и не изменяет файлы. Наличие bundle не даёт право изменять произвольный проект, расширять полномочия или применять process contract без подтверждённой применимости.

Выделение самостоятельной универсальной библиотеки навыков не входит в v0.4. Такой перенос откладывается до подтверждённой отдельной потребности и нового human decision.

## Состав и неизменность v0.3

Bundle v0.4 содержит шесть skills из `runtime/skills/`; его актуальный состав и версия проверяются repository verifier. Проектные skills v0.3 в `package/template/.hermes/skills/` остаются неизменным stable baseline и не являются источником global skills v0.4.

## Границы установки

Глобальная установка, обновление, удаление, trust, изменение Hermes profile или configuration не разрешаются этим решением. Они требуют отдельного human decision с read-only снимком текущего состава, версией/provenance и восстановимым способом возврата.
