# Режим installer для global runtime ИскИн v0.4

**Дата:** 2026-09-06
**Статус:** human decision для ветки v0.4
**Область:** локальный installer и два допустимых состава portable template; не release v0.4 и не schema v2

## Принятое решение

Installer определяет необходимость project trust по фактическому allowlist проверенного package manifest:

- если manifest содержит файл под `.hermes/skills/` или `.agents/skills/`, сохраняется прежний v0.3 handoff: installer только печатает `hermes skills trust` и не выполняет его;
- если таких файлов нет, installer не печатает `hermes skills trust`, сообщает, что проект использует global skills ИскИн, global runtime должен быть установлен отдельно, а окончательная доступность проверяется в новой сессии Hermes;
- похожие пути вне этих двух точных каталогов не включают project-trust режим.

## Полномочия и границы

Installer сам не устанавливает, не обновляет и не удаляет global skills. Он не меняет Hermes configuration, profile, trust или gateway и не вызывает Hermes или сетевые операции. Установка ограничена проверкой package, переносом его bytes и локальным installation metadata.

Пакет с project-local skills и пакет без них используют одну manifest schema v1 и один проверяемый byte-level allowlist. Полноценный global-runtime installer и manifest schema v2 в этом решении не проектируются. Ветка v0.4 не создаёт release, tag, merge или push этим решением.

## Проверяемый критерий

Оба режима проверяются на полном установочном пути: package validation, installation manifest, установленные bytes и финальное сообщение. Для global-runtime режима отдельно проверяется отсутствие вызова Hermes и отсутствие project trust handoff. Для project-local режима проверяется сохранение прежнего ручного handoff.
