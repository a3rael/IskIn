# Принятие ИскИн v0.3 как стабильной исходной версии

**Дата:** 2026-09-06
**Статус:** стабильная принятая исходная версия
**Тип:** human decision о baseline ИскИн
**Область:** release `0.3.0` и дальнейшее развитие универсального ядра

## Решение

Человек принимает ИскИн `0.3.0` как стабильную исходную версию (baseline) для дальнейшего развития и экспериментов v0.4.

Это решение означает, что текущий состав v0.3, его установочный контракт, lifecycle, quality gates, evidence contract и границы полномочий становятся исходной точкой для следующего цикла разработки. Дальнейшие изменения ядра относятся к v0.4 и требуют отдельного решения человека.

## Основания

- release candidate `0.3.0` воспроизводимо собран;
- временная сборка архива дала ожидаемый SHA-256:

  ```text
  7eafc27305b980b6048e152e2afaa40f4c0e7ea5622773c343a187cfa2aec5ad
  ```

- установка release candidate признана целостной;
- все шесть проектных навыков фактически загружены текущим runtime в установленном smoke-проекте;
- границы lifecycle и полномочий `proved` / `accepted` интерпретированы согласованно;
- новых дефектов установленного ядра не обнаружено.

## Ограничение U-003

U-003 остаётся открытым известным неблокирующим ограничением Hermes Desktop: runtime-доступность проектных навыков может периодически различаться между сессиями и процессами.

U-003 не считается дефектом универсального ядра и не отменяет принятие v0.3 как стабильного baseline. Принятие v0.3 не означает доказанную стабильность runtime Hermes во всех будущих сессиях; устойчивость этого runtime-контракта остаётся отдельным вопросом для наблюдения и возможной работы в v0.4.

## Граница решения

Это решение:

- не изменяет смысл и правила устанавливаемого ядра;
- не изменяет lifecycle, quality gates, evidence scopes или package manifest schema;
- не закрывает и не переписывает U-003;
- не создаёт tag, remote, GitHub Release и не выполняет push;
- не переносит runtime-наблюдение в product memory установленного проекта;
- не объявляет v0.4 начатой.
