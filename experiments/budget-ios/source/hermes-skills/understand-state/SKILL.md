# Understand state

Read `process/`, `product-memory/`, `telemetry/`, the active product and available evidence. Distinguish verified facts from assumptions and self-reported status.

Return a compact snapshot: target result, accepted facts, active outcomes, blocking uncertainties, evidence gaps, regressions and the highest-leverage next decision. Update memory only to correct factual drift or record a newly observed fact; do not change goals or acceptance criteria.
