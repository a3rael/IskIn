# Challenge result

Use only when a trigger in `process/quality-gates.md` applies. Work read-only: do not change code, product intent, result status or acceptance criteria. Start from shared sources of truth but do not rely on the implementation agent's self-assessment.

Try to falsify claimed behavior with an independent check, adversarial scenario or invariant. Record a reproducible counterexample, an evidence gap, or the limits of the search in `product-memory/evidence.md` and `telemetry/run-log.md`. A finding changes state only when it includes evidence.
