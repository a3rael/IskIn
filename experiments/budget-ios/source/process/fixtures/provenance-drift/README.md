# Изолированная process-only drift-фикстура

Эта фикстура предназначена только для безопасной статической проверки provenance-контракта. Она не запускает Budget MVP, Xcode, iOS Simulator или любой продуктовый runner и не создаёт product evidence.

Шаблонные данные находятся в `template/`. Если когда-либо потребуется отдельное упражнение, копия создаётся только в новом каталоге:

```text
process/fixtures/provenance-drift/runs/<run_id>/
```

`<run_id>` выбирается один раз и не переиспользуется. Файлы `manifest.json`, `report.md` и `proof-record.json` принадлежат только этому каталогу. Перезапись существующего каталога или любого исторического файла запрещена.

В текущем изменении упражнение не выполнялось: каталог `runs/` содержит только этот контракт, а шаблонный report имеет статус `not-run`.

Проверяемый сценарий (только как будущая спецификация): зафиксировать SHA-256 нейтрального текстового input, изменить его копию, выполнить fingerprint checkpoint, создать invalidation event и убедиться, что это не меняет product-memory, Budget MVP или product evidence.
