# ИскИн

ИскИн — универсальная система agent-native PDLC для Hermes Agent и Hermes Desktop.

Система должна помогать Hermes автономно доводить утверждённое продуктовое намерение до принятого результата с воспроизводимыми доказательствами, обязательным уровнем качества и минимальным содержательным управлением человека.

## Статус

Текущая версия — `0.4.0`, обычный опубликованный релиз, Latest и рекомендуемая текущая основа ИскИн. Дальнейшее развитие ведётся в `v0.5`.

`0.3.0` остаётся предыдущей стабильной исходной версией и baseline, но больше не является рекомендуемой текущей основой.

- `package/` — устанавливаемый пакет;
- `installer/` — локальный установщик;
- `docs/` — документация ИскИн;
- `experiments/` — материалы и результаты полигонов.

Известное ограничение U-003 — периодическая runtime-доступность проектных навыков Hermes Desktop — остаётся открытым и неблокирующим. Принятие v0.3 не означает доказанную стабильность runtime Hermes во всех будущих сессиях.

Обычный статус v0.4.0 не означает доказанную полную автономность, отсутствие ошибок или принятие продуктового эксперимента с Telegram-ботом. Ограничения evidence/lifecycle, восстановления между сессиями и telemetry сохраняются.

Документ выпуска: [`docs/releases/v0.4.0-experimental-prerelease.md`](docs/releases/v0.4.0-experimental-prerelease.md). Решение о текущем статусе: [`docs/decisions/2026-09-13-v0.4-ordinary-release-status.md`](docs/decisions/2026-09-13-v0.4-ordinary-release-status.md).

Budget-специфичные правила и код не входят в универсальный пакет автоматически.
