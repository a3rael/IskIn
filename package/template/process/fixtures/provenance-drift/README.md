# Нейтральная provenance-фикстура

Эта фикстура предназначена только для проверки процесса `scope drift → fingerprint mismatch → invalidation event`. Она не запускает продуктовый код и не создаёт product evidence.

Если упражнение будет разрешено отдельно, каждый запуск создаётся в новом каталоге `runs/<run-id>/`. Существующие каталоги и файлы не перезаписываются.
