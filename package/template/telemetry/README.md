# Telemetry

Эта папка в распространяемом шаблоне содержит только пустые структуры и определения. Исходный шаблон не содержит фактических данных продукта, среды или результатов циклов.

После установки в проект Hermes записывает сюда наблюдения и результаты существенных циклов согласно действующим правилам `telemetry/` и `process/`. Такие записи относятся к установленному проекту, а не к исходному распространяемому шаблону.

- явный read-only запрос пользователя сохраняет приоритет;
- при таком запросе не создавай и не изменяй записи telemetry;
- не объявляй наблюдение или результат сохранённым, если запись не выполнялась.

- `run-log.md` — фактический контекст существенных циклов;
- `metrics.md` — определения метрик и границы измерения.

Плановое завершение сессии между проверенными переходами является частью первого recovery-эксперимента, а не содержательным human steering. Не записывай его или другие фактические product outcomes, environment или результаты проверок в исходный распространяемый шаблон.
