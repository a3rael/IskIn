# Устанавливаемый пакет

Каталог `template/` содержит утверждённый нейтральный шаблон ИскИн v0.3 для нового или пустого продуктового проекта Hermes.

Пакет включает универсальные процессные правила, read-only executable lifecycle gate в `.iskin/`, versioned machine state, product memory, telemetry и шесть продуктово-независимых проектных навыков. Продуктовый код, quality gates, evidence scopes, runners и фактические evidence добавляются владельцем установленного проекта.

Исторические материалы экспериментов в пакет не копируются. Установочный контракт находится в `docs/installation/README.md`; канонический standalone-исходник установщика v0.3 находится в `../installer/install-iskin.py`.
